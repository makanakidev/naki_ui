`package:naki_ui/framework.dart` provides runtime building blocks, responsive query providers, lifecycle management, gesture handlers, and state controllers.

---

## What's Included

- 📱 **Responsive Engine**: `MediaQueryProvider` with viewport width, height, and orientation query utilities.
- 🎮 **Controllers**: `OverlayController` (for dialogs, sheets, drawers, and snackbars), `ScrollController`, and `PageController`.
- 🌐 **Lifecycle & Browser**: `NakiStatefulMixin` (`afterRender`) and `BrowserLifecycleListeners` (visibility, resize, and component size observation).
- 👆 **Gestures & Animation**: `GestureDetector`, `Gestures`, `Events`, `GestureRecognizer`, and easing `Curves`.
- 🛠️ **Utilities**: `NakiDebounce` and typed `BuildContext` extensions.
