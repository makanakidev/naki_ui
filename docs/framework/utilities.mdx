## `PlatformData`

Access device, browser environment, operating system, and viewport information safely across both client and server (SSR / SSG) environments:

```dart
import 'package:naki_ui/framework.dart';

// Uses ambient browser window/location on web, or default server values on SSR
final platform = PlatformData();

// Device & OS detection
final isApple = platform.isiOS || platform.isMacOS;
final isMobile = platform.isMobile;
final isDesktop = platform.isDesktop;
final deviceName = platform.device; // 'iPhone', 'iPad', 'MacOS', 'Windows', 'Android', 'Linux'

// PWA & Browser environment
final isPWA = platform.isPWA; // Running as an installed Progressive Web App
final isMobileBrowser = platform.isMobileBrowser; // Mobile browser (not running as standalone PWA)

// Viewport dimensions & locale
final width = platform.width;
final height = platform.height;
final locale = platform.language; // e.g. 'en'

// URL & Base Origin
final currentPath = platform.currentUrl; // e.g. '/dashboard'
final baseOrigin = platform.baseUrl; // e.g. 'https://example.com'
```

`PlatformData` automatically resolves to the client-side implementation on web browsers and the server-side implementation during SSR/SSG pre-rendering or testing.

The constructor accepts optional override parameters, which is particularly useful for server-side rendering, testing, or custom URL resolution:

```dart
final customPlatform = PlatformData(
  baseUrl: 'https://example.com',
  currentUrl: '/settings',
  userAgent: 'Mozilla/5.0...',
  width: 1440,
  height: 900,
  language: 'en',
);
```

| Parameter    | Type      | Default (Client)         | Default (Server)               | Description                         |
| ------------ | --------- | ------------------------ | ------------------------------ | ----------------------------------- |
| `baseUrl`    | `String?` | `window.location.origin` | `'/'`                          | Base URL origin of the application  |
| `currentUrl` | `String?` | Path without `baseUrl`   | `'/'`                          | Current URL path with leading slash |
| `userAgent`  | `String?` | `navigator.userAgent`    | `''`                           | User agent header string            |
| `width`      | `int?`    | `window.innerWidth`      | `0`                            | Viewport width in pixels            |
| `height`     | `int?`    | `window.innerHeight`     | `0`                            | Viewport height in pixels           |
| `language`   | `String?` | `navigator.language`     | `Platform.localeName` / `'en'` | Preferred locale or language code   |

### Common Use Cases

#### 1. Conditional UI for Mobile / Desktop

```dart
import 'package:jaspr/jaspr.dart';
import 'package:naki_ui/framework.dart';
import 'package:naki_ui/naki_ui.dart';

class AdaptiveShortcutHint extends StatelessComponent {
  const AdaptiveShortcutHint({super.key});

  @override
  Component build(BuildContext context) {
    final platform = PlatformData();

    if (platform.isMobile) {
      return const NakiText('Tap search icon above');
    }

    final shortcut = platform.isMacOS ? '⌘K' : 'Ctrl+K';
    return NakiText('Press $shortcut to search');
  }
}
```

#### 2. PWA Installation Prompt

```dart
class PwaPromotionBanner extends StatelessComponent {
  const PwaPromotionBanner({super.key});

  @override
  Component build(BuildContext context) {
    final platform = PlatformData();

    // Display banner only on mobile browsers when not already installed as standalone PWA
    if (platform.isMobileBrowser) {
      return const Banner(
        text: 'Install this app on your device for a full-screen experience!',
      );
    }

    return .empty();
  }
}
```

## `NakiDebounce`

Rate-limit high-frequency operations such as search text input, auto-save requests, and window resizing:

```dart
import 'package:naki_ui/framework.dart';

// Debounce search text input with a unique tag
void onSearchChanged(String query) {
  NakiDebounce.run(
    'search-input',
    const Duration(milliseconds: 300),
    () {
      fetchSearchResults(query);
    },
  );
}

// Immediately fire pending execution
void forceSearchNow() {
  NakiDebounce.fire('search-input');
}

// Cancel pending execution
void cancelSearch() {
  NakiDebounce.cancel('search-input');
}
```

## `BuildContext` Extensions

Naki UI extends `BuildContext` with convenient theme, mode, and token getters:

```dart
// Access design tokens
final tokens = context.themeTokens;

// Access active theme mode
final mode = context.themeMode;

// Toggle theme between light/dark/system
context.toggleTheme();

// Set specific mode
context.setTheme(ThemeMode.dark);

// Direct color token shortcuts
final primary = context.primaryColor;
final secondary = context.secondaryColor;
final background = context.backgroundColor;
final surface = context.surfaceColor;
final text = context.textColor;
final muted = context.mutedColor;
final border = context.borderColor;

// Apply opacity to a color
final semiTransparent = context.withOpacity(primary, 0.5);
```

## `String` & Nullish String Extensions

Text formatting, case conversion, validation, and data sanitization utilities:

```dart
// Case conversion
final title = 'hello world dashboard'.toTitleCase(); // 'Hello World Dashboard'
final sentence = 'welcome user. please review.'.toSentenceCase(); // 'Welcome user. Please review.'

// Currency & truncation
final currency = '12500.5'.toCurrency(); // '$12,500.50'
final truncated = 'Very long description text here'.truncate(20); // 'Very long descriptio...'
final initials = 'John Doe'.initials; // 'JD'

// Validations & links
final validEmail = 'user@example.com'.isEmail; // true
final validUrl = 'https://nakiverse.com'.isUrl; // true
final link = 'Check https://dart.dev now'.extractLink; // 'https://dart.dev'

// Data sanitization
final rawNumbers = 'Order #123-456!'.withoutSymbols; // 'Order123456'
final base64Clean = 'data:image/png;base64,iVBORw...'.base64Only;

// Nullish safety on nullable String?
String? input = '   ';
if (input.isNullOrEmpty) {
  // true for null, empty, or whitespace-only strings
}
if (input.isNotNullAndEmpty) {
  // true only when string contains non-whitespace characters
}
```

## `num` Extensions

Currency formatting, precision rounding, and CSS dimension conversion:

```dart
final amount = 4500.5.toCurrency('₦'); // '₦4,500.50'
final rounded = 4.12879.roundTo(2); // 4.13
final up = 4.2.roundUp; // 5
final down = 4.9.roundDown; // 4

final isInt = 4.0.isInteger; // true
final isDbl = 4.25.isDouble; // true

final clean = 4.0.toCleanString; // '4'
final pxVal = 16.toPx; // '16px'
```

## `DateTime` Extensions

Comprehensive date, time, and relative duration formatters:

```dart
final now = DateTime.now();

// Formatted date strings
final shortDate = now.toDdMmmYyyy; // '28th, Sep 2026'
final fullDate = now.toDdMmmmYyyy; // '28 September 2026'
final monthYear = now.toMonthYear; // 'September 2026'
final slashedDate = now.toDateWithSlashes; // '28/09/2026'
final dayMonthYear = now.toDayMonthYear; // 'Mon Sep 28, 2026'

// Formatted time strings
final timeAmPm = now.toTimeAmPm; // '10:30 PM'
final militaryTime = now.toTime; // '22:30'
final fullTime = now.toFullTimeAmPm; // '10:30:45 PM'
final timeWithTz = now.toTimeWithTimeZone('UTC'); // '10:30 PM UTC'

// Combined date and time
final fullDateTime = now.toDateTime; // '28th, Sep 2026 - 10:30 PM'
final longDateTime = now.toDateTimeLong; // 'September 28, 2026, 10:30 PM'
final slashedDateTime = now.toDateAndTimeWithSlashes; // '28/09/2026 10:30 PM'

// Date comparisons
final isToday = now.isToday; // true
final isSame = now.isSameAs(otherDate);
final isBefore = now.isBeforeOrSameAs(deadline);

// Relative & duration utilities
final dueText = deadline.timeRemaining(beforeDueDate: 'remaining', afterDueDate: 'overdue');
final countdown = deadline.timeRemainingUntil(); // '04:39:01:58'

// Reactive client-side time ago notifier (updates automatically every second for recent dates)
final timeAgoNotifier = messageDate.timeAgoNotifier; // ValueNotifier('2m ago')
```

## `ValueListenable` Extension

Inline declarative UI rebuilds from a `ValueListenable` or `ValueNotifier`:

```dart
final counter = ValueNotifier<int>(0);

// Declaratively binds component rebuilds to value changes
counter.rebuild((count) => NakiText('Count: $count'))
```

## CSS Map Extensions (`Map<String, String>`)

Manipulate raw style maps and convert them to valid CSS string declarations:

```dart
final baseStyles = {'display': 'flex', 'gap': '12px'};
final extraStyles = {'align-items': 'center', 'color': 'red'};

final merged = baseStyles.combine(extraStyles);
// {'display': 'flex', 'gap': '12px', 'align-items': 'center', 'color': 'red'}

final filtered = merged.except(['color']);
// {'display': 'flex', 'gap': '12px', 'align-items': 'center'}

final picked = merged.only(['display', 'gap']);
// {'display': 'flex', 'gap': '12px'}

final cssString = merged.cssText;
// 'display: flex; gap: 12px; align-items: center; color: red;'
```
