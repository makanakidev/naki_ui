Scaffolding components provide the foundational structure of standard web application layouts exported from `package:naki_ui/naki_ui.dart`.

---

## `Scaffold`

`Scaffold` implements the top-level visual layout structure for a page, integrating an app bar, modal drawer, persistent sidebar, main body, bottom navigation, and floating action button.

### Use Case: Complete Application Layout

```dart
import 'package:jaspr/jaspr.dart';
import 'package:jaspr_icons_pack/jaspr_icons_pack.dart';
import 'package:naki_ui/naki_ui.dart';

class DashboardLayout extends StatelessComponent {
  const DashboardLayout({super.key});

  @override
  Component build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        titleText: 'Analytics Dashboard',
        actions: [
          Button.icon(
            MaterialIcons.notifications,
            semanticLabel: 'Notifications',
            onTap: () {},
          ),
        ],
      ),
      sideBar: Sidebar(
        width: const Dim.px(240),
        child: Padding(
          padding: const EdgeInsets.all(Dim.px(16)),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            spacing: 8,
            children: [
              const Bold('Workspace'),
              Button.text('Projects', onTap: () {}),
              Button.text('Team Members', onTap: () {}),
            ],
          ),
        ),
      ),
      body: const Padding(
        padding: EdgeInsets.all(Dim.px(24)),
        child: NakiText('Main Dashboard Content'),
      ),
      bottomNavigationBar: BottomNavigationBar(
        selectedIndex: _currentIndex,
        type: BottomNavigationBarType.frostedGlass,
        onTap: (index) => setState(() => _currentIndex = index),
        items: const [
          BottomNavigationBarItem(
            icon: LucideIcons.icon_house,
            label: 'Home',
          ),
          BottomNavigationBarItem(
            icon: LucideIcons.icon_settings,
            label: 'Settings',
          ),
        ],
      ),
    );
  }
}
```

## `Drawer` & `Sidebar` Navigation

`Scaffold` provides dedicated slots for both modal drawer navigation and persistent desktop sidebar navigation:
- **`drawer` (`Drawer`)**: Modal slide-in navigation overlay with a darkened barrier backdrop. Can be opened programmatically using `Scaffold.maybeOf(context)?.openDrawer()`.
- **`sideBar` (`Sidebar`)**: Persistent side navigation panel docked alongside the page body without an overlay backdrop barrier.

```dart
Scaffold(
  drawer: Drawer(
    position: DrawerPosition.left,
    child: Padding(
      padding: const EdgeInsets.all(Dim.px(16)),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        spacing: 8,
        children: [
          const Heading('Menu', level: 3),
          Button.text('Home', onTap: () {}),
          Button.text('Settings', onTap: () {}),
        ],
      ),
    ),
  ),
  sideBar: Sidebar(
    width: const Dim.px(240),
    child: Padding(
      padding: const EdgeInsets.all(Dim.px(16)),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        spacing: 8,
        children: [
          const Heading('Workspace', level: 4),
          Button.text('Overview', onTap: () {}),
          Button.text('Analytics', onTap: () {}),
        ],
      ),
    ),
  ),
  body: const NakiText('Page body content'),
)
```

## `AppBar`

`AppBar` renders a theme-aware top navigation header with elevation, leading component slot, title text/component, and action items:

```dart
AppBar(
  leading: Button.icon(
    MaterialIcons.arrow_back,
    semanticLabel: 'Back',
    onTap: () {},
  ),
  titleText: 'User Profile',
  actions: [
    Button.filled(
      const Color('#2563eb'),
      child: const NakiText('Save'),
      onTap: () {},
    ),
  ],
)
```

## `BottomNavigationBar`

Renders a bottom navigation bar for mobile and compact responsive layouts:

```dart
BottomNavigationBar(
  selectedIndex: 1,
  onTap: (index) => print('Selected tab: $index'),
  items: const [
    BottomNavigationBarItem(icon: MaterialIcons.home, label: 'Home'),
    BottomNavigationBarItem(icon: MaterialIcons.search, label: 'Search'),
    BottomNavigationBarItem(icon: MaterialIcons.person, label: 'Profile'),
  ],
)
```

## `BottomNavigationBarType` Enum Variants

| Enum Variant                           | Description                                                                                                                                          |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BottomNavigationBarType.frostedGlass` | The bottom navigation bar has an iOS-style frosted glass effect, is elevated, centered on the screen, and has a smaller width than the screen width. |
| `BottomNavigationBarType.floating`     | The bottom navigation bar is elevated, centered on the screen, and has a smaller width than the screen width.                                        |
| `BottomNavigationBarType.fixed`        | The bottom navigation bar is fixed to the bottom of the screen and has the full width of the screen.                                                 |
