Naki UI provides 80+ modular, accessible UI components. All components, and the `show*` overlay functions, are exported directly from `package:naki_ui/naki_ui.dart`.

---

<Info>
  **New in 1.0.6:**

  - **[`showDialog`](/components/overlays#dialog)**, **[`showModalBottomSheet`](/components/overlays#bottomsheet)** and **[`showSnackbar`](/components/overlays#snackbar)**: Show an overlay without a controller, as in Flutter. The dialog and sheet futures complete with the value passed to `closeDialog` or `closeModalBottomSheet`.
  - **[`Card.glass`](/components/layout#container-card)** and **`Dialog(glass: true)`**: Translucent glass surfaces with accessibility fallbacks.
  - **[`BottomNavigationBarType.liquidGlass`](/components/scaffold#liquid-glass)**: A glass bottom navigation bar that bends the content behind it.
  - **[`CalendarType.range`](/components/inputs#date-ranges)**: Pick a start and end date with `initialRange`, `onSelectedRange` and `rangeValidator`.
  - **[`AppBar`](/components/scaffold#appbar)**: New `fixed` and `blurBackground` properties.
</Info>
