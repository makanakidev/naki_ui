Input components provide accessible form controls with built-in validation, floating labels, helper text, and icon slots.

---

## `TextField`

The standard text field supporting password masking, validation callbacks, helper text, and multi-line modes:

```dart
import 'package:jaspr/dom.dart';
import 'package:jaspr/jaspr.dart';
import 'package:naki_ui/naki_ui.dart';

TextField(
  id: 'user-email',
  type: InputType.email,
  decoration: const InputDecoration(
    labelText: 'Email Address',
    placeholderText: 'name@example.com',
    helperText: 'We will send your verification code here',
  ),
  autoValidate: true,
  validator: (value) {
    if (value == null || !value.contains('@')) {
      return 'Please enter a valid email address';
    }
    return null;
  },
  onTyping: (text) => print('Current text: $text'),
  onSubmit: (text) => print('Submitted text: $text'),
)
```

## `FormBuilder`

`FormBuilder` manages declarative HTML form validation and submission. It features built-in `direction` (`Direction.vertical` or `Direction.horizontal`) and `spacing` parameters:

```dart
final formKey = GlobalNodeKey<HTMLFormElement>();

FormBuilder(
  formKey: formKey,
  direction: Direction.vertical,
  spacing: 16,
  bypassValidation: true,
  children: [
    const Heading('Account Information'),
    TextField(
      id: 'username',
      type: InputType.text,
      required: true,
      decoration: const InputDecoration(
        labelText: 'Username',
        placeholderText: 'Choose a username',
      ),
    ),
    TextField(
      id: 'password',
      type: InputType.password,
      required: true,
      decoration: const InputDecoration(
        labelText: 'Password',
        placeholderText: 'Enter your password',
      ),
    ),
    Button.filled(
      const Color('#0f766e'),
      child: const NakiText('Submit Form'),
      validateForm: true, // Triggers FormBuilder validation before onTap
      onTap: () {
        print('Form validated and submitted!');
      },
    ),
  ],
)
```

## `AutoCompleteField`

Text field with dynamic autocomplete dropdown suggestions:

```dart
AutoCompleteField(
  id: 'framework-search',
  options: const ['Jaspr', 'Flutter', 'Dart', 'Next.js', 'Vue'],
  decoration: const InputDecoration(
    labelText: 'Search Frameworks',
    placeholderText: 'Type to filter options...',
  ),
  onSelected: (selection) {
    print('Selected framework: $selection');
  },
)
```

## `SegmentedInput` (OTP / PIN Verification)

Specialized multi-character segmented input for OTP codes, PINs, and verification sequences:

```dart
SegmentedInput(
  id: 'pin-verification',
  length: 6,
  type: SegmentedInputType.number,
  onCompleted: (pin) {
    print('Completed 6-digit PIN: $pin');
  },
)
```

## `Calendar`

Date, time, and date range selection component:

```dart
Calendar(
  id: 'booking-calendar',
  type: CalendarType.date,
  initialValue: DateTime.now(),
  minimum: DateTime(2020),
  maximum: DateTime(2030),
  onSelected: (date) {
    print('Selected date: $date');
  },
)
```

### Date ranges

Use `CalendarType.range` to select a start and end date. Range calendars use `initialRange`, `onSelectedRange`, and `rangeValidator`; `onSelected` is not called.

```dart
Calendar(
  id: 'trip-dates',
  type: CalendarType.range,
  initialRange: [DateTime(2026, 10, 25), DateTime(2026, 10, 30)],
  minimum: DateTime(2026),
  autoValidate: true,
  rangeValidator: (days) {
    if (days == null) return 'Select your travel dates';
    if (days.length > 14) return 'Maximum 14 days allowed';
    return null;
  },
  onSelectedRange: (days) {
    print('${days.first} to ${days.last} (${days.length} days)');
  },
  decoration: const InputDecoration(labelText: 'Travel dates'),
)
```

- **`initialRange`**: dates can be in any order and their time is ignored. The earliest and latest dates set the range, and a single date is a one-day range. All dates must be within `minimum` and `maximum`.
- **`onSelectedRange`**: receives every day from the start date through the end date in ascending order, so a list it emits can be passed back as `initialRange`.
- **`rangeValidator`**: receives the same list, or `null` when nothing is selected. It runs before `validator`, which receives only the start date.
- **Selecting**: the first click sets the start date and the next click sets the end date. Clicking an earlier date starts a new range, and clicking the start date again selects one day.
- **Confirming**: `Ok` stays disabled until the range has an end date. Pressing `Escape`, pressing `Cancel`, clicking outside the picker, or clicking the trigger discards an unconfirmed selection.
- **Forms**: the start date is submitted under the calendar's `id` and the end date under `{id}_end`, both as `yyyy-MM-dd`.
