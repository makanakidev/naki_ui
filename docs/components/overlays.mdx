description: Modals, bottom sheets, alert dialogs, toast snackbars, popovers, drawers, and tooltips in Naki UI.
---

Overlay components present contextual dialogs, notifications, flyout sheets, and tooltips. All overlays integrate with typed `OverlayController` instances for smooth animations and focus management.

---

## `Snackbar`

Toast notification positioned dynamically at the top or bottom of the viewport:

```dart
import 'package:jaspr/jaspr.dart';
import 'package:naki_ui/naki_ui.dart';

final snackbarController = OverlayController();

// Trigger button
Button.filled(
  const Color('#2563eb'),
  child: const NakiText('Show Notification'),
  onTap: () => snackbarController.open(),
)

// Snackbar component
Snackbar(
  controller: snackbarController,
  content: const NakiText('Profile changes saved successfully!'),
  position: SnackbarPosition.bottom,
  duration: const Duration(seconds: 4),
)
```

Or show one without a controller, as in Flutter. `showSnackbar` closes any snackbar already open, and `closeSnackbar()` closes the current one early:

```dart
showSnackbar(
  context,
  const Snackbar(content: NakiText('Profile changes saved successfully!')),
);
```

## `Dialog`

Accessible modal dialog with focus trapping and backdrop blur:

```dart
final dialogController = OverlayController();

Dialog(
  controller: dialogController,
  title: 'Confirm Deletion',
  subtitle: 'Are you sure you want to permanently delete this project?',
  actions: [
    Button.text(
      'Cancel',
      onTap: () => dialogController.close(),
    ),
    Button.filled(
      const Color('#ef4444'),
      child: const NakiText('Confirm'),
      onTap: () {
        performDelete();
        dialogController.close();
      },
    ),
  ],
)
```

Or show one without a controller with `showDialog`, which completes with the value passed to `closeDialog`, or `null` when the barrier dismisses it:

```dart
final confirmed = await showDialog<bool>(
  context: context,
  builder: (context) => Dialog(
    title: 'Confirm Deletion',
    barrierDismissible: true,
    actions: [
      Button.text('Cancel', onTap: () => closeDialog(context, false)),
      Button.text('Delete', onTap: () => closeDialog(context, true)),
    ],
  ),
);
```

Both need a `NakiApp` or `Scaffold` above `context`; the overlay keeps that context, so it sits clear of the app bar and bottom navigation bar.

Set `glass: true` for a translucent dialog. `backgroundColor` sets the tint, and the barrier stops blurring so the glass can see the page. See `Card.glass` for the `glassTint`, `glassRim` and `glassBlur` theme values and the accessibility fallbacks.

## `BottomSheet`

Slide-up sheet suited for mobile and compact responsive layouts:

```dart
final sheetController = OverlayController();

BottomSheet(
  controller: sheetController,
  child: Padding(
    padding: const EdgeInsets.all(Dim.px(24)),
    child: Column(
      mainAxisSize: MainAxisSize.min,
      crossAxisAlignment: CrossAxisAlignment.stretch,
      spacing: 12,
      children: [
        const Heading('Share Document', level: 3),
        Button.text('Copy Public Link', onTap: () {}),
        Button.text('Send via Email', onTap: () {}),
      ],
    ),
  ),
)
```

Or show one without a controller with `showModalBottomSheet`. `builder` returns the sheet's content, and the future completes with the value passed to `closeModalBottomSheet`, or `null` when the barrier dismisses it:

```dart
final target = await showModalBottomSheet<String>(
  context: context,
  builder: (context) => Column(
    mainAxisSize: MainAxisSize.min,
    children: [
      Button.text('Messages', onTap: () => closeModalBottomSheet(context, 'messages')),
      Button.text('Mail', onTap: () => closeModalBottomSheet(context, 'mail')),
    ],
  ),
);
```

## `Popover` & `Tooltip`

Anchored contextual flyouts and hover tooltips:

```dart
// Popover shown on hover or focus
Popover(
  child: Button.text('Options', onTap: () {}),
  position: PopoverPosition.bottomLeft,
  content: const Padding(
    padding: EdgeInsets.all(Dim.px(12)),
    child: NakiText('Popover content panel'),
  ),
)

// Popover controlled by its parent: hover and focus do nothing, and tapping
// outside the content or scrolling the page calls onClose
Popover(
  visible: _open,
  onClose: () => setState(() => _open = false),
  child: Button.text('Options', onTap: () => setState(() => _open = true)),
  content: const NakiText('Popover content panel'),
)

// Hover/focus Tooltip
Tooltip(
  text: 'Refresh analytics feed',
  child: Button.icon(
    MaterialIcons.refresh,
    semanticLabel: 'Refresh',
    onTap: () {},
  ),
)
```

`Popover` and `Tooltip` open at `position` and stay anchored to their trigger inside the safe areas and the Scaffold's bars: they flip to the opposite side when only that side fits, and slide along the trigger when they would cross an edge. A tooltip's arrow keeps pointing at the trigger. Once placed, they scroll with the trigger and are only placed again when the viewport's width changes.

## `Drawer`

Modal navigation drawer that slides in from the left or right edge over a darkened backdrop:

```dart
final drawerController = OverlayController();

// Trigger button
Button.icon(
  MaterialIcons.menu,
  semanticLabel: 'Open Navigation Drawer',
  onTap: () => drawerController.open(),
)

// Modal Drawer component
Drawer(
  controller: drawerController,
  position: DrawerPosition.left,
  width: const Dim.px(300),
  child: Padding(
    padding: const EdgeInsets.all(Dim.px(16)),
    child: Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      spacing: 12,
      children: [
        const Heading('Navigation', level: 3),
        Button.text('Dashboard', onTap: () => drawerController.close()),
        Button.text('Settings', onTap: () => drawerController.close()),
      ],
    ),
  ),
)
```

## Motion

`Dialog`, `BottomSheet` and `Drawer` follow Material 3 motion:

| Overlay       | Opening                                                                                     | Closing                                       |
| :------------ | :------------------------------------------------------------------------------------------ | :-------------------------------------------- |
| `Dialog`      | Grows from 35% of its height over 500ms on the emphasized curve, then its content fades in | Shrinks and fades over 150ms (emphasized accelerate) |
| `BottomSheet` | Slides up over 210ms                                                                        | Slides down over 120ms                        |
| `Drawer`      | Slides in over 210ms                                                                        | Slides out over 120ms                         |

The scrim fades its own color and blur, so the overlay above it is never see-through. Under `prefers-reduced-motion`, overlays appear and disappear without animating.
